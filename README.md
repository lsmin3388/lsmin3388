### 학교에서

컴퓨터학부 학생 1,483명이 쓰는 학생회 플랫폼을 만들고 운영해요. 로그인은 Keycloak으로 SSO를 붙였고 학생회비 납부랑 사물함 배정은 서비스를 따로 뒀습니다. 서버는 학부에 있는 물리서버예요. Ubuntu에 Docker Compose, Nginx, SSL까지 직접 올렸고 배포는 GitHub Actions가 합니다.

2024년과 2025년엔 과대표, 2026년엔 제17대 학생회장.
